# Book Recommender System 📚

This project is a **Content-Based + Collaborative Filtering Book Recommendation System**, built by following [Krish Naik's tutorial](https://www.youtube.com/watch?v=Q7mS1VHm3Yw).

It recommends books based on user preferences using a combination of:
- Book titles
- Ratings
- Similarity scores

## 🔧 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit (for the web app)

## 🚀 Getting Started

### 1. Clone the repo

git clone https://github.com/AlmuarikAmal/book_recommender.git
cd book_recommender

### 2. Create a virtual environment
python -m venv .venv
source .venv/bin/activate  

### 3. Run the app
python gradio-dashboard.py
